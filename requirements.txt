# Python dependencies — Acies AgenticBus: Product Lifecycle & Portfolio Intelligence

# Tested on CPython 3.14.4 (Windows 11).  Versions are pinned exactly because the
# dataset is deterministic: main.py seeds every RNG with 20260909 and validate.py
# asserts 16 reconciliation targets.  A different NumPy or SciPy can change
# floating-point results enough to move a target outside tolerance, so an
# unpinned install would silently produce a different dataset.
#
#     python -m venv .venv
#     .venv\Scripts\activate          # Windows
#     source .venv/bin/activate       # macOS / Linux
#     pip install -r requirements.txt
#
# Regenerate the dataset with:  python data/generator/main.py
